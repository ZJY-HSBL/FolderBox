# FolderBox v1.11.1

FolderBox v1.11.1 is a maintenance and Windows filesystem-safety update to v1.11.0.

## Changes

- Reject Windows reserved device names that use superscript digit variants, preventing invalid filenames and related file-operation errors.
- Tighten repository ignore rules for local and generated artifacts.
- Preserve the existing v1.11.0 Workspace safety checkpoint and restore behavior.

## 更新内容

- 补充对带上标数字形式的 Windows 保留设备名的检测，防止无效文件名引发文件操作错误。
- 优化仓库忽略规则，避免提交本地及生成文件。
- 保留 v1.11.0 的工作区安全检查点与恢复行为。

## Downloads / 下载

- `FolderBox-Setup-1.11.1.exe`: Windows installer / Windows 安装包。
- `FolderBox-Portable-1.11.1.zip`: portable package / 便携版。
- `SHA256SUMS.txt`: release artifact checksums / 文件校验值。

The Windows release workflow runs lint and tests, packages both distributions, verifies output, and publishes the GitHub Release after successful completion.
