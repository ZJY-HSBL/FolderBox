# FolderBox v1.9.0

FolderBox v1.9.0 makes saved Workspaces portable and easier to branch.

## Highlights

- Export a saved Workspace to a versioned `folderbox-workspace` JSON file.
- Import Workspace files for backup restoration or transfer between FolderBox installations.
- Automatically resolve imported name conflicts, for example `Research` → `Research (2)`.
- Duplicate an existing Workspace directly from the Workspace manager.
- Preserve Box state and automatic layout policy across export/import and duplication.
- Generate Windows-safe suggested export filenames.
- Normalize imported folder paths against the current machine.
- Intentionally exclude global `Ctrl+Alt+1…9` bindings from exported and duplicated Workspaces to prevent shortcut conflicts.

## Portability Behavior

If an imported Box points to a folder that does not exist on the current machine, FolderBox clears that folder binding while preserving the Box's remaining saved state. The user can then bind a new local folder manually.

## Downloads

This release provides:

- `FolderBox-Setup-1.9.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.9.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
