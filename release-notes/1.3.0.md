# FolderBox v1.3.0

FolderBox v1.3.0 focuses on desktop layout control and faster Workspace operation.

## Highlights

- Automatic Box snapping to screen edges and neighboring Boxes.
- One-click placement commands for the left, right, top, bottom, and center of the current screen.
- A tray toggle for enabling or disabling Box snapping globally.
- Quick previous/next Workspace switching directly from the tray.
- Native Windows global hotkey `Ctrl+Alt+B` for hiding or showing all Boxes from anywhere.
- Global hotkey availability is shown in the tray only when Win32 registration actually succeeds.
- Box geometry is saved when title-bar dragging finishes instead of during every movement.
- Desktop snapping and placement calculations are isolated in a reusable layout module with regression tests.

## Downloads

This release provides:

- `FolderBox-Setup-1.3.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.3.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
