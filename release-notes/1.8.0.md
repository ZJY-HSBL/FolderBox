# FolderBox v1.8.0

FolderBox v1.8.0 adds a dedicated Workspace Quick Switcher for fast keyboard-driven desktop switching.

## Highlights

- Open the Workspace Quick Switcher globally with `Ctrl+Alt+Space`.
- Search saved Workspaces by name without opening the full Workspace manager.
- Use Up/Down to move through results, Enter to switch, and Escape to close.
- See each Workspace's Box count, automatic layout policy, active state, and assigned `Ctrl+Alt+1…9` shortcut.
- Open the same Quick Switcher from the system tray.
- Keep Quick Switcher registration independent from dynamic numeric Workspace hotkeys.
- Continue using `Ctrl+Alt+B` for global Box hide/show.

## Downloads

This release provides:

- `FolderBox-Setup-1.8.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.8.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Notes

The Quick Switcher global shortcut uses Win32 `RegisterHotKey`. If `Ctrl+Alt+Space` is already reserved by Windows or another application, the switcher remains available from the tray but the global shortcut will not be advertised as active.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
