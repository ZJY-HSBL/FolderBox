# FolderBox v1.1.0

FolderBox v1.1.0 turns the project from a simple desktop folder viewer into a persistent Windows desktop folder portal.

## Highlights

- System tray residency with hide/show-all controls.
- Named Workspaces that restore complete multi-Box desktop layouts.
- Per-Box custom titles, always-on-top state, opacity, and layout locking.
- Back / Forward / Up navigation with a clickable breadcrumb path bar.
- Instant current-folder filtering with optional wildcard patterns.
- Background copy, move, and recycle-bin operations to keep the UI responsive.
- Cut/paste move semantics, direct folder creation, and improved Windows filename validation.
- Optional launch-at-login integration.
- A cleaner compact title bar with low-frequency controls moved into an overflow menu.

## Downloads

The release provides:

- `FolderBox-Setup-1.1.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.1.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

FolderBox v1.1.0 is built with PyInstaller and Inno Setup. The release pipeline runs Ruff and pytest first, verifies that `FolderBox.exe` was generated, builds both installer and portable packages, generates checksums, and only then publishes the GitHub Release.
