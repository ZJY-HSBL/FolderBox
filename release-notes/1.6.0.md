# FolderBox v1.6.0

FolderBox v1.6.0 turns layout templates into persistent Workspace behavior.

## Highlights

- Assign an optional automatic layout policy to each saved Workspace.
- Choose between keeping saved positions, balanced grid, horizontal columns, vertical rows, or cascade.
- Automatically reapply the selected policy whenever that Workspace is loaded or reached through previous/next Workspace cycling.
- Configure or clear a Workspace policy directly from the Workspace manager.
- See the active automatic layout policy directly in the Workspace list.
- Preserve layout-policy metadata when a Workspace is renamed.
- Remove layout-policy metadata automatically when a Workspace is deleted.
- Keep the configuration model simple with a dedicated `workspace_layouts` mapping.

## Downloads

This release provides:

- `FolderBox-Setup-1.6.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.6.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
