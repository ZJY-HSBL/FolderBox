# FolderBox v1.2.0

FolderBox v1.2.0 focuses on personalization, Windows integration, and smoother desktop file interaction.

## Highlights

- Per-Box light and dark themes.
- Per-Box accent colors with presets and a custom color picker.
- Configurable icon sizes plus Ctrl + mouse-wheel zoom in icon view.
- A dedicated Workspace manager for switching, saving, renaming, and deleting layouts.
- Optional Windows Explorer `Open in FolderBox` context-menu integration.
- Single-instance local IPC so Explorer requests and repeated launches are routed to the already-running FolderBox process.
- Explicit multi-selection drag-out support for dragging files and folders from FolderBox to the desktop, Explorer, and other file-drop targets.
- External folder requests reuse an empty Box when possible and otherwise open a managed Box that inherits current appearance settings.

## Downloads

This release provides:

- `FolderBox-Setup-1.2.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.2.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
