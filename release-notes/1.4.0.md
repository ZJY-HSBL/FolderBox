# FolderBox v1.4.0

FolderBox v1.4.0 upgrades Workspace handling from saved coordinates to active desktop arrangement.

## Highlights

- Multi-Box layout templates for balanced grid, horizontal columns, vertical rows, and cascade arrangements.
- One-click layout templates directly from the system tray.
- Current-desktop arrangement controls inside the Workspace manager.
- Multi-monitor-aware arrangement: each display organizes only the visible, unlocked Boxes currently on that screen.
- Locked Boxes remain untouched by automatic arrangement.
- Dense row and column layouts automatically wrap when a single row or column would make Boxes smaller than their minimum usable size.
- Layout template geometry is isolated in the desktop layout module and covered by regression tests.

## Downloads

This release provides:

- `FolderBox-Setup-1.4.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.4.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
