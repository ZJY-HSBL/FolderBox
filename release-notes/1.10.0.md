# FolderBox v1.10.0

FolderBox v1.10.0 adds local Workspace checkpoints for safe layout rollback.

## Highlights

- Create named restore points for any saved Workspace.
- Active Workspaces capture their current live Box state instead of only the last persisted copy.
- Restore Box geometry, appearance, bound folders, and the automatic layout policy in one action.
- Keep Workspace global hotkey assignments unchanged when restoring a checkpoint.
- Manage checkpoints from a dedicated dialog with create, restore, delete, timestamps, Box counts, and layout metadata.
- Preserve checkpoint history when a Workspace is renamed.
- Remove checkpoint history automatically when its Workspace is deleted.
- Keep checkpoints local to the current FolderBox installation.
- Workspace duplication and portable Workspace export/import intentionally do not carry checkpoint history.

## Downloads

This release provides:

- `FolderBox-Setup-1.10.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.10.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
