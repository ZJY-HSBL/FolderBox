# FolderBox v1.11.0

FolderBox v1.11.0 makes Workspace checkpoint restore reversible by default.

## Highlights

- Automatically create a safety checkpoint immediately before restoring an older Workspace checkpoint.
- Abort the restore if FolderBox cannot capture the current Workspace state first.
- Keep the latest 10 automatic safety checkpoints per Workspace.
- Never prune manually created checkpoints as part of automatic retention.
- Mark automatic safety checkpoints clearly in the checkpoint manager.
- Preserve compatibility with v1.10 checkpoint data; missing `automatic` metadata is treated as a manual checkpoint.
- Safety checkpoints capture the current Workspace Box state and automatic layout policy before rollback.

## Downloads

This release provides:

- `FolderBox-Setup-1.11.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.11.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
