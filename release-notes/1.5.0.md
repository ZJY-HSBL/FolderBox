# FolderBox v1.5.0

FolderBox v1.5.0 adds optional edge-peek behavior for individual desktop Boxes.

## Highlights

- Per-Box edge auto-hide with hover-to-expand behavior.
- Auto-hidden Boxes keep a narrow trigger strip visible at the screen edge instead of shrinking below FolderBox's minimum window size.
- Edge-peek preference is persisted per Box and inside Workspaces.
- Collapsed off-screen geometry is runtime-only; saved state always uses the expanded Box position.
- Global show-all, Explorer/IPC folder opens, manual placement, and multi-Box automatic arrangement expand edge-peek Boxes before acting.
- Pointer-leave collapse is delayed to reduce accidental hiding and is suppressed while popup menus are active.
- Edge geometry and expanded-state persistence are covered by dedicated regression tests.

## Downloads

This release provides:

- `FolderBox-Setup-1.5.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.5.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
