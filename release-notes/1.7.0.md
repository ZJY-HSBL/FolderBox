# FolderBox v1.7.0

FolderBox v1.7.0 adds global Workspace shortcuts for faster desktop switching.

## Highlights

- Assign `Ctrl+Alt+1` through `Ctrl+Alt+9` to saved Workspaces.
- Switch directly to a Workspace from any Windows application without focusing FolderBox first.
- Configure or clear Workspace hotkey slots in the Workspace manager.
- See assigned shortcuts in both the Workspace list and the system tray.
- Keep the existing `Ctrl+Alt+B` global hide/show shortcut.
- Refresh Win32 hotkey registrations immediately when Workspace bindings change.
- Preserve hotkey bindings when a Workspace is renamed.
- Remove bindings automatically when a Workspace is deleted.
- Reject duplicate or invalid shortcut slots.

## Downloads

This release provides:

- `FolderBox-Setup-1.7.0.exe` — standard Windows installer.
- `FolderBox-Portable-1.7.0.zip` — portable build.
- `SHA256SUMS.txt` — SHA256 checksums for release artifacts.

## Notes

Workspace shortcuts use Win32 `RegisterHotKey`. If a chosen combination is already reserved by Windows or another application, that slot cannot become active until the conflict is removed.

## Packaging

The release pipeline validates the package version, runs Ruff and pytest on Windows, builds FolderBox with PyInstaller, verifies `FolderBox.exe`, compiles the installer with Inno Setup, creates the portable archive, generates SHA256 checksums, and only then publishes the GitHub Release.
